               INTRODUÇÃO
     Este  texto  fornece a você informações "on-line" sobre seu dBASE II
Sistema de Gerenciamento de Banco de Dados . Usando o comando HELP em 
conjunto com seu Manual, você logo estará escrevendo "procedures" com os
comandos do sistema e ele trabalhará para você.



               COMO USAR O COMANDO "HELP"
     Informações sobre seu dBASE II podem ser obtidas simplesmente digitando-se
HELP e uma das seguintes palavras-chaves (ex. HELP FUNÇÕES )

     UTILITÁRIOS     TELA-CHEIA     LIMITES
     COPIA           ERROS          HELP
     FUNÇÕES         DBASE
          (ou outro comando dBASE)

dBASE então procurará o texto correspondente  à palavra-chave e o
mostrará . Se não houver informações para este, dBASE dirá "Não há mensagem
HELP ".   Quando houver mais texto a ser mostrado, então você verá a palavra
Esperando.

     Os principais arquivos em disco usados pelo dBASE são :

          DBASE.COM      --arquivo-programa principal
          DBASEOVR.COM   --todos os overlays e mensagens do sistema
          DBASEMSG.TXT   --este arquivo HELP (desnecessário se não for
                         usado o comando HELP)
          COPIA.BAT      --programa para cópia do dBASE do disco mestre
                         para o disco do usuário com 40 ou 80 colunas.
          DGEN.CMD       --programa em dBASE que gera programas em dBASE
                         para gerar arquivos (GERAARQ), etiquetas
                         (GERAETIQ), menus (GERAMENU) e relatórios
                         (GERAREL).

*EXIT
*TELA-CHEIA
          CODIGOS DE MOVIMENTO DO CURSOR NA TELA
     CTRL-X move  cursor p/baixo do próximo campo (tambem CTRL-F)
     CTRL-E move  cursor p/cima  do próximo campo (tambem CTRL-A)
     CTRL-D move  cursor p/frente do caracter
     CTRL-S move  cursor p/trás do caracter
     CTRL-G apaga o caracter sobre o cursor
     CTRL-Y apaga o campo corrente a direita do cursor
     CTRL-V alterna o modo INSERT ON / INSERT OFF
     CTRL-W salva qualquer modificação feita e retorna ao dBASE
          (tambem CTRL-O)

          NO MODO DE EDIÇÃO - EDIT
     CTRL-U inverte a marca DELETE on/off
     CTRL-C grava registro corrente e avança para o próximo registro
     CTRL-R grava registro corrente e retorna para registro anterior
     CTRL-Q ignora modificações feitas e retorna ao  dBASE
     CTRL-W grava todas as modificações feitas e retorna ao dBASE



          NO MODO BROWSE
     CTRL-B leva a janela p/direita um campo
     CTRL-Z leva a janela p/esquerda um campo

          NO MODO DE MODIFICAÇÃO - MODIFY
     CTRL-T apaga a linha corrente e move as seguintes para cima
     CTRL-N insere uma nova linha na posição do cursor
     CTRL-C alimenta uma linha no vídeo
     CTRL-W grava todas as modificações no disco e retorna ao dBASE
     CTRL-Q ignora todas as modificações e retorna ao dBASE

          NO MODO DE CONCATENAÇÃO - APPEND
     <enter> quando o cursor está na primeira posição do primeiro campo
          irá terminar o comando APPEND
     CTRL-W  grava registro no disco e avança para próximo registro
     CTRL-Q  ignora o registro corrente e retorna ao dBASE

          CHAVES DE CONTROLE QUANDO NÃO EM TELA-CHEIA
     CTRL-P alterna o modo da impressora em on/off
     CTRL-R repete a último comando dBASE executado
     CTRL-X apaga a linha de comando sem executá-lo
     CTRL-H backspace
     CTRL-M funciona exatamente como um <enter>

*EXIT
*ADATE
> ADATE -- acrescenta dias a uma data.
        Sintaxe: PLUS ADATE <data 1> <dias>  <parâmetro> TO <data 2>
                            (DDMMAA) (3 pos)   (1 pos)      (DDMMAA)
        Retorno: se parâmetro = "0" soma os dias a partir da <data 1>
              retorno em <data 2>.
              se parâmetro = "1" soma os dias a partir do primeiro
              dia do mes seguinte a <data 1>, retorno em <data 2>.
*EXIT 
*APPEND
> APPEND FROM <arquivo> [FOR <exp>] ou
> APPEND FROM <arquivo> [SDF] [DELIMITED] [FOR <exp>]
     -- adiciona dados (FROM) de um arquivo no formato de dados do  sistema
        para o banco de dados em uso. Registros marcados para exclusão no
        FROM <arquivo> não serão acrescentados.

> APPEND BLANK -- acrescenta um branco, isto é, um registro vazio no arquivo .

> APPEND -- permite ao usuário adicionar novos dados ao banco de dados em uso .
     (se indexação estiver sendo usada, o aquivo de índices é atualizado)

*CDATE
> CDATE -- determina a validade de uma data.
        Sintaxe: PLUS CDATE < data > TO < resp >
                            (DDMMAA)     (1 pos)
        Retorno: se < resp > = '1' , data válida
                 se < resp > = '0' , data inválida.
*EXIT
*CGC
> CGC -- verifica a validade de um C.G.C.
      Sintaxe: PLUS CGC < varcgc > TO < resp >
                         (14 pos)      (1 pos)
      Retorno: se < resp > = '1' , CGC válido
               se < resp > = '0' , CGC inválido.

*CHANGE
> CHANGE -- Permite edição de banco de dados em uso por  campo.  Digite
         ESCape para terminar o modo CHANGE .
         Sintaxe: CHANGE [<alcance>] FIELD <lista> [FOR <exp>]

> PLUS CHANGE -- transforma a pontuação do sistema Americano para o Europeu.
           Sintaxe: PLUS CHANGE < valor 1 > TO < valor 2 >
           Entrada: < valor 1 > = valor com pontuação Americana
           Retorno: < valor 2 > = valor com pontuação Européia.

*COPY
> COPY -- Copia o banco de dados em uso ou somente sua estrutura para outro

       copiar registros marcados para exclusão.

  Sintaxe: COPY TO <arquivo> [<alcance>] [FIELD <lista>] [FOR <exp>]
        COPY TO <arquivo> [SDF] [DELIMITED [WITH <delimitador>]] [FOR <exp>]
        COPY TO <arquivo> STRUCTURE [FIELD <lista>]

Para acessar o texto de um comando dBASE (ou outro texto HELP) que você quer

*SET
> SET -- configura parâmetros  de controle do dBASE .

          Sintaxe: SET <parâmetro> [ON ou OFF]
                SET <parâmetro> TO <opção>

     Todos os comandos SET estão listados abaixo em ordem alfabetica :
     Note que alguns SETs não são do tipo (ON/OFF), e outros requerem
     algumas opções a serem dadas pelo usuário . O valor default de
     ON/OFF é indicado em letras minúsculas em cada exemplo .
       ex.      SET BELL [ON/off] -- valor  default é ON .

> SET ALTERNATE [OFF/on] -- ON transfere todas as saidas de tela (exceto tela-
     cheia) para um arquivo em disco. (Este comando deve ser precedido do
     comando SET ALTERNATE TO <arquivo>). OFF desliga estas saidas .

> SET BELL [ON/off] -- ON emite um bip quando dados inválidos são entrados
     ou o limite do campo é ultrapassado . OFF suspende o sinal do bip.

> SET CARRY [OFF/on] -- ON  repete dados no registro corrente de um registro
     anterior quando usando APPEND no modo Tela-Cheia.  OFF deixa o campo
     em branco .

> SET COLON [ON/off] -- ON mostra ":" para limitar o tamanho de um campo de
     entrada. OFF suspende esta função .

> SET CONFIRM [OFF/on] -- ON desabilita salto automatico para o próximo campo
     quando o campo corrente é preenchido quando em modo Tela-Cheia. OFF
     espera por um <return> para saltar para o próximo campo .

> SET CONSOLE [ON/off] -- ON transfere todas as saidas para a tela. OFF cancela
     esta função .

> SET DELETED [OFF/on] -- ON desabilita o comando de pesquisa FIND ou o
     processamento de registros marcados para exclusão .

> SET DEBUG [OFF/on] -- ON transfere a saída criada por ECHO e STEP para
     a impressora.   OFF transfere a saída para a tela .

> SET ECHO [OFF/on] -- ON habilita a monitoração da execução de um arquivo
       de comandos ecoando todos os comandos na tela. OFF desabilita a função .

> SET EJECT [ON/off] -- ON força o comando REPORT para executar uma alimentação
     de formulário antes de executar qualquer relatório na
     impressora . OFF desabilita a função .

> SET ESCAPE [ON/off] -- ON permite o usuário abortar a execução de um
     arquivo de comandos pressionando a tecla ESC . OFF desabilita esta 
     função .

> SET EXACT [OFF/on] -- ON requer combinações exatas em qualquer comparação
     de strings de caracteres (em comandos FOR <exp>, FIND , etc.).
     OFF permite a combinação entre strings de diferentes tamanhos .

> SET INTENSITY [ON/off] -- ON habilita vídeo inverso ou intensidade dupla em
       operações Full-Screen (se permitido pelo hardware).  OFF desabilita esta
       função .No MSX não tem significado.

> SET LINKAGE [OFF/on] -- ON habilita movimento de ponteiros de registros nas
     áreas PRIMARY e SECONDARY, por comandos que permitem um <alcance>,
     isto é, somente no movimento para baixo . OFF suspende o ponteiro .

> SET PRINT [OFF/on] -- ON tranfere a saída para impressora . OFF cancela a
     saída .

> SET  RAW  [OFF/on]  -- ON permite usar o comando DISPLAY e LIST para mostrar
       os registros sem espaços inseridos entre os campos . OFF mostra colunas
       de dados com espaçamento entre eles .

> SET SCREEN [ON/off] -- ON habilita operações Tela-Cheia para APPEND, EDIT,
     INSERT, READ, e CREATE .

> SET STEP [OFF/on] -- ON permite a execução passo a passo de um arquivo
     de comandos . OFF não para a execução à cada passo .

> SET TALK [ON/off] -- ON mostra o resultado de cada execução de comando na
     tela . Off suspende esta função .

> SET ALTERNATE TO [<arquivo>] -- cria um arquivo em disco da familia .TXT para
     salvar as saidas de tela . SET ALTERNATE TO fecha o arquivo .TXT .

> SET DATE TO <xx/xx/xx> -- armazena uma string na data do sistema , mas não
     executa a validação desta data .

> SET DEFAULT TO <drive> -- faz com que o drive especificado seja aquele no
     qual dBASE irá procurar os arquivos, quando instruido .

> SET FORMAT TO <SCREEN / print> -- SCREEN transfere a saída de um comando
     @ SAY para a tela . PRINT transfere a saída formatada para impressora.

> SET FORMAT TO [<arquivo formato>] -- abre um arquivo .FMT, o qual dBASE irá
     utilizar para formatar a tela para os comandos READ, APPEND, EDIT,
     INSERT, CREATE, @ SAY . SET FORMAT TO fecha todos os arquivos ainda
     abertos .

> SET HEADING TO <string> -- salva <string> internamente e a imprime como
     uma linha de cabeçalho de relatório .

> SET INDEX TO <arquivo indexado> -- faz com que arquivos indexados sejam
     usados com o banco de dados em uso . Outros arquivos indexados serão
     fechados . SET INDEX TO fecha todos os arquivos indexados .

> SET MARGIN TO <n> -- leva a margem esquerda da impressora para <n> colunas.

*FUNÇÕES
> @ --  @(<string1>,<string2>) - Esta função faz pesquisa de <string1> em 
     <string2>, resultando um número inteiro que é a posição referente a 
     <string2>. Caso <string1> não seja encontrado em <string2>, retornará
     com o valor zero.

> * -- função de exclusão de registro avalia como Verdadeiro (TRUE) lógico se o
       registro corrente foi marcado para exclusão .

> # -- função de número de registro dá o valor de um inteiro correspondente
       ao número de registro corrente .

> ! -- !(<string>)  - função que produz uma  <string> em letras maiúsculas .

> $ -- $(<string>,<inicio>,<tamanho>) - função de substring, produz uma
       string de caracteres a partir de uma determinada string .


> CHR -- CHR(<expressão numérica>) - produz o caracter ASCII equivalente
      a <expressão numérica>.  

> DATE()  -- retorna uma string de caracteres contendo a data do sistema no
      no formato DD/MM/AA.

> EOF     -- função de fim de arquivo (end-of-file). Avalia como verdadeiro
          (TRUE) se for ultrapassado o último registro do arquivo.

> FILE -- FILE(<arquivo>) - função que avalia como Verdadeiro (TRUE) se um
       determinado (arquivo) existe no drive corrente .

> INT -- INT(<expressão numérica>) -- função inteira que arrendonda para
      o menor valor mais próximo do número .

> LEN -- LEN(<string>) -- função que retorna o número de caracteres que possui
      a <string>.

> RANK -- RANK(<string>) -- retorna o valor (número ASCII) do caracter mais
       a esquerda de  <string>.

> STR -- STR(<expressão numérica>,<largura>[,<decimais>]) - função que converte
      uma expressão numérica para uma string de caracteres .

> VAL -- VAL(<string>) - função que converte uma string de caracteres feita por
      números em uma expressão numérica.

> TRIM -- TRIM(<string>) - função que remove espaços em branco a direita de
       uma <string>.   

> TYPE -- TYPE(<exp>) - função que produz uma string de um caracter contendo
       um 'C','N','L',  ou 'U' se a <exp> é do tipo  Caracter ,  Numérica,
       Lógica, ou Indefinida .

> TEST -- 0  =  TEST(<exp>) - função que determina se <exp>  é
       válida e  analisável. <exp> poderá ser uma expressão numérica ou
       outra função , um nome de campo ,  ou outra combinação (mas não
       uma palavra de comando dBASE).  Uma  <exp> válida retorna um 1.
       Conforme o valor de <exp> funciona como LEN.

*ERROS

"Campo decimal inválido" -- Reentre a parte decimal da definição do campo .

"Nome de arquivo inválido" -- Erro de sintaxe no nome do arquivo .

"Nome de campo inválido" -- Redefina o nome do arquivo enquanto em CREATE .

"Tipo de campo inválido" -- Deve ser C (caracter), N (numérico), ou L (lógico).

"Tamanho de campo inválido" -- Redefina o tamanho do campo de entrada .

"*** Além da string"  - Reescreva substring ($) com o parâmetro correto .

"Não pode inserir, não há registros no banco de dados" -- Use o comando
     APPEND no lugar.

"Não pode abrir arquivo" -- Cheque a existencia ou integridade de um arquivo
     MEM ou HEX.

"Arquivo de comando não encontrado -- Cheque o nome do arquivo ou o drive
     default.

"Dado não encontrado" -- Reescreva o comando  REPLACE , ou veja a estrutura
     do arquivo e o nome correto de campo .

"Banco de dados em uso não é indexado" - FIND é permitido somente em banco de
     dados indexados .

"Diretório está cheio" --  O sistema operacional não pode gravar mais arquivos
     no disco .

"Disco está cheio" -- Não há mais espaço no disco . Use o comando DELETE FILE
     para apagar arquivos desnecessários e conseguir mais espaço .

"Fim de arquivo inesperado" -- O banco de dados em uso (USE) não está no
     formato correto . dBASE não assegura que o arquivo é do tipo DBF .

"FIELD não encontrado" -- Reescreva a linha de comando CHANGE .

"Arquivo já existe" -- Delete o arquivo desnecessário antes de usar RENAME .

"Arquivo não existe" -- Use DISPLAY FILE LIKE *.* para ter certeza se o
     arquivo realmente existe .

"Arquivo no momento está aberto" -- Use um comando USE ou CLEAR para fechar
     este arquivo .

"Arquivo de formato não pode ser aberto" -- Cheque a integridade deste arquivo.

"Arquivo de formato não foi configurado" -- Use o arquivo .FMT apropriado .

"Tipo de dado ilegal" -- SORT não pode sortear um campo lógico .

"Valor ilegal para GO TO" -- Endereçamento de registro deve ser maior que 0
     e menor que 65534.

"Nome de variável ilegal" -- Somente alfanuméricos e "_" são permitidos em
     variáveis e nomes de campos . Redefina a variável ou nome do campo .

"Indice não compatível com o banco de dados" -- dBASE não pode combinar a chave
     indexada com o banco de dados . Tente outro arquivo indexado .

"Arquivo de índices não pode ser aberto" --  Cheque nome ou índice do banco de
     dados .

"Tentativa de gerar mais que 65534 registros" -- A cláusula FOR permite
     ligação de demasiados registros . Faça-o mais comprimido .

"Chaves não são do mesmo tamanho" -- Comando UPDATE requer chaves idênticas .

"Macro não é cadeia de caracteres" -- A variável a ser expandida pela macro
     (&) deve ser uma string de caracteres .

"Mais que 5 campos a somar" -- SUM é limitado a 5 campos ao mesmo tempo.

"Mais do que 7 arquivos indexados selecionados"- - O número máximo de arquivos
     indexados abertos ao mesmo tempo é 7 . Um número menor dará melhor
     performance.

"Excedido o limite de encaixes" -- Não pode haver mais de 16 arquivos de
     comandos abertos ao mesmo tempo .

"Sem expressão para somar" -- Comando SUM necessita de uma expressão numérica .

"FOR não encontrado" -- Reescreva comando  JOIN  com a sintaxe correta .

"FROM não encontrado" -- Reescreva comando UPDATE com a sintaxe correta .

"Não encontrado" -- Mais um diagnóstico que uma mensagem de erro . dBASE não
     pode descobrir a chave . O número de registro é colocado em 0 .

"Expressão não numérica -- Comando SUM necessita de uma expressão numérica .

"Arquivo não é banco de dados do dBase II-- Arquivo DBF aberto não foi criado
     pelo dBase II.

"ON não encontrado" -- Reescreva o comando UPDATE ou INDEX corretamente .

"Sem espaço para variáveis de memória -- Reduza o número ou tamanho das
      variáveis de memória .

"Tamanho do registro ultrapassa o limite de 1000 bytes" -- Reduza o tamanho de
     alguns campos ou crie um segundo banco de dados com a mesmo chave .

"Registro não indexado" -- Arquivo indexado não atualizado após um registro ter
     sido incluido . REINDEX o arquivo .

"Registro fora de alcance" -- Número do registro chamado é maior que o número
     de registros do banco de dados . O arquivo indexado não está
     atualizado . Reindexe o arquivo com o comando REINDEX .

"Erro interno , notifique suporte" -- Contacte o departamento de suporte da
     DATALOGICA.

"Tipo de dado da origem não é o mesmo do destino" -- Cheque se tipos de dados
     são ambos numéricos , ambos caracteres ou ambos lógicos .

"*** Erro de sintaxe ***" -- dBASE não entendeu o comando .

"Erro de sintaxe na especificação do formato" -- O comando @ SAY GET PICTURE
     foi usado impropriamente .

"Erro de sintaxe, redigite" -- INPUT, ACCEPT, REPORT requerem automaticamente
     entrada correta .

"TO não encontrado" -- Reescreva o comando com a sintaxe correta .

"Excesso de caracteres" -- Somente quando não em modo TELA-CHEIA. O dado
      entrado excedeu o tamanho alocado para aquele campo .

"Excesso de arquivos abertos" -- Somente 16 arquivos de todos os tipos (.FMT,
     .NDX ou de COMANDOS) podem ser abertos ao mesmo tempo .

"Excesso de variáveis de memória -- Use no máximo 64 variáveis de memória  .

"Excesso de RETURNs encontrado" -- Provavelmente um erro na estrutura de um
     arquivo de comandos . Cheque o número e a localização de RETURNs.

"WITH não encontrado" -- Reescreva comando  REPLACE corretamente .

"Número de arquivo não designado" -- Erro interno , entre em contato com  o
     suporte. Se HELP é usado, DBASEMSG.TXT deve existir no drive corrente.

"*** Comando desconhecido" -- Cheque o conteúdo. dBASE não conseguiu 
     interpretar o comando.

"Variável não foi encontrada -- Precisa-se criar a variável ou checar o
     conteúdo do nome do campo na estrutura do banco de dados .

"*** Divisão por ZERO ***" -- Houve uma tentativa de divisão por zero .
